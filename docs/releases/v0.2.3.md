# CaliphBar v0.2.3

这是 CaliphBar 的私有测试版视觉精修更新，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- 将侧栏圆环统一为 36 点，并重新校准模块间距，为顶部、底部和 Radar 百分比保留更稳定的安全区
- 使用 2.25 点外环与低饱和仪表色，移除 0% 时没有真实进度却出现的伪光点
- 按 Claude、Codex 和 Antigravity 的视觉重量分别校准标志尺寸、饱和度与亮度
- 新增“深色 / 暖瓷白”圆环内芯切换，并持久保存用户选择
- 暖瓷白采用克制的陶瓷渐变、细黑隔离圈和浅底专用标志校准；Radar 同步使用更深的青色
- 侧栏、悬浮详情、完整面板和菜单栏额度共用百分比取整与阈值语义
- 正常额度在黑色侧栏上显示为中性浅色，在浅色系统菜单栏上显示为中性深色；黄色和红色仍只表示低额度警示
- 保持菜单栏 Provider 的持久选择规则：只有完整管理面板中的明确选择会更新菜单栏，侧栏悬停或点击仍只切换临时详情

本次更新只调整界面呈现和选择一致性，不改变 Claude、Codex、Antigravity 或 Reset Radar 的数据来源与安全边界。

## 安装方法

1. 下载 `CaliphBar-v0.2.3-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，请先确认文件来自本私有仓库且校验值一致，再执行：

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行：

```bash
shasum -a 256 -c CaliphBar-v0.2.3-macOS-universal.zip.sha256
```
