# CaliphBar v0.2.7

这是 CaliphBar 的系统级 UI 与交互体验提升版本，适用于 macOS 13 及以上系统，同时原生支持 Apple Silicon 与 Intel 架构。

## 本版内容

- **菜单栏控制台「0.1 秒一眼尽览」Tab 状态胶囊**：
  - 在顶栏各个 Provider 选项卡（Claude / Codex / Antigravity）内直接内嵌实时剩余额度百分比微标与健康状态色彩点；
  - 打开控制台瞬间即可纵览三家模型额度状态，无需来回切换 Tab。
- **用量条「悬停绝对时间即时翻转」与「官方控制台一键直达」**：
  - 鼠标掠过任意一行用量条时，右侧倒计时（如 `2d 6h 14m 后`）立即平滑翻转为具体绝对时刻（如 `今天 18:30` 或 `周日 08:00`），移出后自动复原，无需等待系统 Tooltip；
  - 控制台与详情卡头部提供极简直达按钮，可一键在默认浏览器打开对应平台的官方用量管理后台。
- **状态栏「动态 Mini Gauge 微型表盘」**：
  - 替换掉通用的静态系统图标，采用 Core Graphics 动态渲染 16×16 pt 微型机械表盘；
  - 外圈弧线根据当前 Provider 的实际剩余百分比精确按比例展开，内圈嵌入平台专属微缩核心；正常状态自适应 macOS 系统外观，额度告急时自动转为醒目警示色。
- **纯黑曜石剪影与侧栏触感回馈**：
  - 坚决保持极简、纯粹、高雅的纯黑贝塞尔剪影轮廓，不使用任何破坏纯粹感的生硬外发光；
  - 展开侧栏内部节点加入细腻的弹性缩放与高光回馈，滑动切换更灵动。
- **本地工程 Spotlight 索引重复治理**：
  - 本地构建 bundle 默认注入 `.metadata_never_index`，彻底消除开发工作区构建产物被 Spotlight / 启动台误搜为双份 App 的问题。

## 安装方法

1. 下载 `CaliphBar-v0.2.7-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，请先确认文件来自本私有仓库且校验值一致，再执行：

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行：

```bash
shasum -a 256 -c CaliphBar-v0.2.7-macOS-universal.zip.sha256
```
