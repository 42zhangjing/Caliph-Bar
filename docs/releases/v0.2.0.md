# CaliphBar v0.2.0

这是 CaliphBar 首个可下载的私有测试版，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- 全新的 Instrument Console 主面板与设置界面
- 更紧凑的左右屏幕边缘常驻侧栏
- Claude、Codex 与 Antigravity 的本机额度读取
- Antigravity 四条真实额度窗口
- Codex 本机实时 `account/rateLimits/read` 数据
- 独立的 Reset Radar 公共情报模块
- 明确的实时、旧数据、估算与离线状态
- 更大的按钮命中区、等宽数字和平滑的侧栏轮廓

## 安装方法

1. 下载 `CaliphBar-v0.2.0-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，可在终端执行下面的命令，然后重新右键打开。

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行下面的命令核对文件是否完整。

```bash
shasum -a 256 -c CaliphBar-v0.2.0-macOS-universal.zip.sha256
```
