# CaliphBar v0.2.11

适用于 macOS 13 及以上系统，同时原生支持 Apple Silicon 与 Intel 架构。

## 本版内容

- **Claude 无凭据时显示“未检测到凭据”**：
  - 未检测到 Claude Code 登录凭据时，不再显示按预算折算的估算百分比，避免误导；
  - 仅使用 Claude 桌面 App 的用户没有可读取的实时数据源，会看到明确的未登录提示。
- **近期真实读数优先于估算**：实时读取失败时，6 小时内的最近一次真实读数（`STALE`）不再被本地估算值顶掉。
- **Codex 额度刷新更可靠**，并使用 AIHOT 重置事件作为公共情报来源（#27）。

## 安装方法

1. 下载 `CaliphBar-v0.2.11-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，请先确认文件来自官方 Release 且校验值一致，再执行：

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行：

```bash
shasum -a 256 -c CaliphBar-v0.2.11-macOS-universal.zip.sha256
```
