# CaliphBar v0.2.4

这是 CaliphBar 的私有测试版交互修复更新，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- 鼠标离开侧边栏与详情卡片的联合区域后，不再固定等待 320ms，立即开始短促退出
- 详情卡片改用可取消、可反向的内容层动画；退出中重新移入时从当前帧恢复，不闪现或等待旧动画
- 保留透明且完全点透的面板表面，避免在 ChatGPT 等半透明窗口上留下矩形轮廓、阴影或需要下一次输入才消失的合成缓存
- 鼠标在侧边栏与详情卡片之间移动时，联合悬停区域会继续跟踪并可靠收回
- 整条可见黑色侧边栏轮廓都可用于上下拖动，不再限于 Provider 图标区域
- 收起把手移除内部灰白竖线，只保留黑色折叠轮廓
- 系统打开“减少动态效果”时，详情卡片只保留短淡入淡出，不使用缩放或位移

本次更新只修复侧边栏、悬停详情卡片和拖动交互，不改变 Claude、Codex、Antigravity 或 Reset Radar 的数据来源与安全边界。

## 安装方法

1. 下载 `CaliphBar-v0.2.4-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，请先确认文件来自本私有仓库且校验值一致，再执行：

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行：

```bash
shasum -a 256 -c CaliphBar-v0.2.4-macOS-universal.zip.sha256
```
