# CaliphBar v0.2.1

这是 CaliphBar 的私有测试版补丁更新，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- 使用 V3 SVG 作为屏幕边缘侧栏的唯一轮廓母版
- 改善侧栏上下圆弧与屏幕边缘连接处的切线连续性
- SwiftUI 原生路径与 SVG 坐标保持严格一致，并在构建时自动校验
- 额度重置时间统一改为相对倒计时，例如 `2d 6h 14m 后重置`
- 提高重置倒计时文字对比度，同时保留绝对时间提示

## 安装方法

1. 下载 `CaliphBar-v0.2.1-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，可在终端执行下面的命令，然后重新右键打开。

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行下面的命令核对文件是否完整。

```bash
shasum -a 256 -c CaliphBar-v0.2.1-macOS-universal.zip.sha256
```
