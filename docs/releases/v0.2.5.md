# CaliphBar v0.2.5

这是 CaliphBar 的私有测试版功能与外观更新，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- **优雅剪影把手外观**：新增基于原生矢量贝塞尔路径的艺术剪影侧栏外观（`SilhouetteShape`），支持在经典把手与优雅剪影之间自由切换。
- **身体部位定点与悬停显现**：剪影外观在未悬停时呈现纯粹的极简黑色剪影；鼠标悬停时，4 处精准映射在身体轮廓上的图标与额度数据（Claude=头部、Codex=胸部、Antigravity=臀部、Radar=底座）自然淡入显现，并支持触发对应 Provider 的详情浮窗。
- **动效与尺寸平滑缩放**：解决收起把手（152 pt）与展开态（360 pt）之间的缩放过渡，消除贴边缝隙与上下端点台阶，保持 120fps 丝滑无闪烁。
- **常驻展开与设置适配**：偏好设置新增“侧栏外观”（经典 / 优雅剪影）切换选项；在“常驻展开”模式下剪影保持 360 pt 大尺寸展示。

本次更新重点增强侧栏外观定制性与交互趣味性，不改变 Claude、Codex、Antigravity 或 Reset Radar 的数据来源与安全边界。

## 安装方法

1. 下载 `CaliphBar-v0.2.5-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，请先确认文件来自本私有仓库且校验值一致，再执行：

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行：

```bash
shasum -a 256 -c CaliphBar-v0.2.5-macOS-universal.zip.sha256
```
