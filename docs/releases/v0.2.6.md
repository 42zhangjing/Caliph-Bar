# CaliphBar v0.2.6

这是 CaliphBar 的私有测试版细节体验与视觉高精度优化更新，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- **优雅剪影全路径高保真矢量光顺**：
  - 采用 G2 连续切线贝塞尔曲线重构外轮廓及手臂内侧、手肘夹角、发髻空隙等 34 条全部内部闭合子路径；
  - 彻底消除自动位图描摹生成的数百个微观阶梯锯齿与毛刺，100% 锁定解剖极值点与体态比例，呈现极致丝滑的矢量质感。
- **贴屏微隙物理级消除**：
  - 优化外轮廓闭合回路，起点与终点无缝贯穿屏幕外 6pt 防缝缓冲区（\`edgeBleed\`），左右停靠均实现物理外溢覆盖，彻底根治亚像素级贴屏白边或细微裂缝。
- **Logo 圆环位置校准与溢出修复**：
  - 下调 Claude、Codex、Antigravity 锚点坐标，Codex 完整嵌入胸腔丰满区域，彻底消除圆环上沿冒出人体轮廓的瑕疵；
  - 保证内部 4 个点击/悬停探测区域均留有充裕黑底边距。
- **P0 级悬停小尖角动态自适应（Dynamic Pointer Offset）**：
  - 当浮窗靠近屏幕边缘或 Dock 栏被位置修正（clamp）时，小尖角沿卡片边框动态上下滑动，始终垂直精准指向触发气泡圆心，解决贴底错位问题。
- **0% 伪进度点彻底清除**：
  - 额度为 0% 时完全隐藏正上方线帽圆点与微型条形填充，避免形成误导性红点警报；底轨对比度细腻增强。
- **P1 级 Codex Radar 真实深度情报释放与面板死黑治理**：
  - 浮窗完整解析并展示上游返回的深度中文研判长文分析与速蹬窗口状态；
  - 优化紧凑卡片高度与间距，消除 Codex 悬停及完整面板中大面积荒芜死黑，清理文案机械重复。
- **P2 级额度瓶颈判定校准与平滑旋转刷新**：
  - Codex 气泡主额度统一取所有窗口中最小余量，真实反映每周限额枯竭风险，与全局预警逻辑对齐；
  - 刷新按钮提供丝滑连续的 360° 旋转加载动效。

## 安装方法

1. 下载 \`CaliphBar-v0.2.6-macOS-universal.zip\` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 \`/Applications/CaliphBar.app\` 移到废纸篓。
4. 将新的 \`CaliphBar.app\` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，请先确认文件来自本私有仓库且校验值一致，再执行：

\`\`\`bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
\`\`\`

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 \`.sha256\` 文件。可在下载目录运行：

\`\`\`bash
shasum -a 256 -c CaliphBar-v0.2.6-macOS-universal.zip.sha256
\`\`\`
