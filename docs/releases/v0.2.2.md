# CaliphBar v0.2.2

这是 CaliphBar 的私有测试版界面与交互更新，适用于 macOS 13 及以上系统，同时包含 Apple Silicon 与 Intel 架构。

## 本版内容

- 侧栏圆环缩小至 32 点、品牌标志约 17 点，四项模式更疏朗
- 保留原有 48 × 56 点点击区域，不因视觉缩小牺牲交互命中范围
- 移除 Codex 额度数字旁重复的 Radar 状态圆点
- 账户额度统一改用低饱和灰绿、暗金和珊瑚红仪表色
- 菜单栏数字、侧栏圆环、侧边详情和完整面板使用同一套额度颜色
- 菜单栏数字只跟随完整管理面板中明确选择的 Provider
- 侧栏悬停或点击只切换临时详情，不再改写菜单栏的持久选择

## 安装方法

1. 下载 `CaliphBar-v0.2.2-macOS-universal.zip` 并解压。
2. 退出正在运行的 CaliphBar。
3. 将旧的 `/Applications/CaliphBar.app` 移到废纸篓。
4. 将新的 `CaliphBar.app` 拖进“应用程序”。
5. 第一次启动时右键应用并选择“打开”。

当前测试包使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。macOS 若仍然拦截，可在终端执行下面的命令，然后重新右键打开。

```bash
xattr -dr com.apple.quarantine /Applications/CaliphBar.app
```

不要从不可信来源取得 CaliphBar，也不要把任何 Claude、Codex 或 Antigravity 凭据发给他人。

## 校验

同一 Release 附带 `.sha256` 文件。可在下载目录运行下面的命令核对文件是否完整。

```bash
shasum -a 256 -c CaliphBar-v0.2.2-macOS-universal.zip.sha256
```
